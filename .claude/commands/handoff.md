description: Write a handoff note so the next agent or session can continue seamlessly
---
Prepare a handoff for the next agent:

1. Update `STATUS.md`: the statuses of the tasks you touched, any new blockers, open questions and discrepancies.
2. Append to `STATUS.md → Session log` (keep it to 4–6 lines): date · who · what was done (task IDs) · current state (what works, what's half-done, which branch) · exact next step · gotchas discovered.
3. If you learned something non-obvious that future agents need (a provider quirk, a Neon/Vercel gotcha), add it to the relevant doc (e.g. `docs/04-integrations.md`) instead of only the log.
4. Print the handoff summary.
